Forkwise

GitHub token (optional)

Without a token GitHub allows 60 API requests per hour, and one analysis costs up to five. A token raises the budget to 5000 per hour.

Use a fine-grained token with no permissions selected. Forkwise only reads public data; a token with no scopes is enough, and grants Forkwise no access to anything private.

Extension storage is not encrypted. The token is written to your browser profile on disk in plain text, where any program that can read the profile can read it. If that is not acceptable, leave this empty and live with the smaller budget.
